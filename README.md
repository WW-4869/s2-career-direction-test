# 职业方向适配测评 · 纯前端 H5

> 28 道题，测出你天生适合干什么。六维雷达图 + 岗位清单 + 天赋海报，单文件无后端，双击即用。

## 运行

纯静态页面，无构建、无依赖、无第三方 CDN。

- 直接双击 `index.html` 即可打开；
- 或在目录内起本地服务：`python -m http.server 8000`，访问 `http://localhost:8000`。

背景音乐与音效已 base64 内嵌在 `index.html` 中，**不需要额外的 audio 目录**，整个产品就是一个文件（约 2.4MB）。

## 目录结构

```
index.html                     全部内容（样式、脚本、28 道题、结果文案、5 段音频均内联）
marketing/
├── 01-主图.jpg                商品主图（橱窗位）
├── 02-结果页雷达图.jpg         详情页效果图
├── 商品文案.md                标题 / 短描述 / 详情页全文
└── 自动发货话术.md             下单后自动回复话术
.gitignore
README.md
```

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 28 道情景题 | 六维职业兴趣模型，选项加权计分，无对错 |
| 六边形雷达图 | Canvas 绘制，低分区间做保底映射，0 分也有可视化区分度，不会塌缩成一点 |
| Bento 结果页 | 宽屏双列、窄屏单列的自适应卡片网格，内容铺满不偏心 |
| 主导 + 辅助维度 | 组合解读、互补分析、避雷提醒、行动清单 |
| 已选回显 | 回看上一题时，已选选项带 ✓ 标记，可随时改答案 |
| 断点续答 | 作答进度与结果保存在本机 `localStorage`，关掉页面可继续 |
| 天赋海报 | Canvas 750×1000 生成，含雷达图与分数清单，可保存分享 |
| 背景音乐 + 音效 | 循环 BGM 默认开启，答题、提交、揭晓、保存各有专属音效，揭晓时自动压低 BGM |
| 静音开关 | 右下角常驻，状态记在 `localStorage`，刷新后保持 |
| 减少动画 | 识别 `prefers-reduced-motion`，自动关闭过渡与延时 |

## 部署

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main`、目录 `/ (root)`，保存即可，地址形如 `https://<用户名>.github.io/<仓库名>/`。
- **Netlify / Vercel**：直接拖入本文件夹，无需构建命令、无需环境变量。
- **自有服务器 / Nginx**：整个文件夹放到站点目录即可，纯静态无路由要求。

## 说明

- 全部内容免费开放，无付费墙、无登录、无注册、无后端请求；作答只写本机 `localStorage`，不上传任何服务器。
- 背景音乐受浏览器自动播放策略限制，需要用户第一次点击/触摸后才会响起，属正常现象。
- 测评结果仅供娱乐与自我探索参考，不构成职业指导、心理诊断或重大决策依据。
